# Coach setup checklist

The [published setup guide](https://app.trygrowthproject.com/help/setup)
is maintained in `src/public-pages/help-pages.html.ts`.

Coach tools are in The Growth Project mobile app. Ordinary coach tools
do not require a coach subscription; client package payments are separate.

1. Choose the coach option at sign-up and complete the setup wizard.
2. Open **Overview → Get paid** or **Settings → Payouts (Stripe Connect)** for client payments.
3. Create a package in setup or **Settings → Packages**, including recurring packages when appropriate.
4. Share the setup invite or use **Clients → Invite** / **Settings → Invite Codes**.
5. Build and assign training from **Programs**.
6. Set **Settings → Availability** and **Appointment Types**; use **Time Off** and **Booking Inbox**.

After installing, clients should reopen the invite or enter its code.
Confirm the client appears in **Clients**. Free packages work without Stripe.
