# Coach app tour

The [published app tour](https://app.trygrowthproject.com/help/tour)
is maintained in `src/public-pages/help-pages.html.ts`.
Coach tools are in The Growth Project mobile app.

- **Overview**: coaching activity and unfinished setup.
- **Clients**: linked clients, consultations, logs, training, meal plans and conversations.
- **Programs**: build, edit and assign training programs.
- **Messages**: client conversations; alerts depend on phone notification settings.
- **Settings**: packages, Stripe Connect, Money, invites, availability, appointment types and support.

Ordinary coach tools do not require a coach subscription.
Client package payments and Stripe payouts are separate.
Any tour recording should show the mobile app with synthetic accounts only.
