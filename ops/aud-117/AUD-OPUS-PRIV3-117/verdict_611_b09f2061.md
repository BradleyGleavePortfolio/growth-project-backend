## 3. New finding (optional)

**C-611-18: the iPhone path is true on iOS 18 and later only.**
- **Where:** `trust-pages.html.ts:91`.
- **Counterexample.** The app's iOS floor is 16.4: mobile uses `expo ~56.0.12`, `app.json` has no `deploymentTarget` override, and the [Expo SDK 56 changelog](https://expo.dev/changelog/sdk-56) raised the minimum to iOS 16.4. On iOS 17.0, Apple's [iPhone User Guide for iOS 17](https://support.apple.com/guide/iphone/sign-in-with-apple-iph238921d37/17.0/ios/17.0) gives a different path: Settings > [your name] > Password and Security > Apps Using Your Apple ID > Stop Using Apple ID.
- **Why it is only C.** The same text gives the web path, which works on any device and any iOS version, and the page links Apple's maintained article. A person on an older iOS still has two working routes.
- **Fix rule (cheap):** "on an iPhone with iOS 18 or later, open Settings, ..." and "On earlier iOS versions or any other device, sign in at account.apple.com, ...". This wording keeps the spec's Sign-In & Security rule satisfied. Repin `APPLE_NOW` and `APPLE_TODAY`.
- **How to verify:** the updated pins pass, and no sentence containing Sign-In & Security mentions iPhone or Settings.
