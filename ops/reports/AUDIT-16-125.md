## Day-1 reachability (answer first)
The sub-coach feature (invite, accept, sub-coach scope, reassign, revoke) is NOT usable on day 1:
- The Team tab mounts for every coach: `/coach/team/members` always lists the caller as `head_coach`
  (backend src/team/team.service.ts:191-200), so `useCoachRoleType` returns head_coach for every non-sub-coach.
- TeamManagementScreen always shows the plan gate: it reads `plan_tier` from `/auth/me`, which never returns it
  (backend src/auth/auth.service.ts:1451-1459 returns user.profile = UserProfile, no plan_tier), then from the cached
  user, which never has it, and falls back to 'flat_300'. No code ever sets CoachProfile.plan_tier to scale/enterprise.
  => every coach (including the owner) sees a "Team" tab whose only content is "Team management is not included in
  your current plan" (iOS) / "Scale plan required ... Upgrade" (Android; copy covered by m#412).
- Even past the gate, the invite dead-ends: the invite URL is `${PUBLIC_INVITE_BASE_URL}/sub-coach/<token>`
  (backend src/sub-coaches/sub-coach-invite.service.ts:730-736), the app has no route for it, and no mobile code calls
  `POST /sub-coaches/invites/accept`.
- Backend team-mode `POST /team/sub-coaches` (direct assignment, no invitee consent) is tier-locked to pro/enterprise
  via STRIPE_PRICE_PRO/ENTERPRISE, which are not in the production secrets workflow or runbook (only
  STRIPE_PRICE_ID_FITNESS is), so every coach resolves to tier 'unknown' -> 403 team_mode_locked. Not reachable day 1.
What IS reachable day 1: the Team tab (gate only) and Settings -> Business -> "Team / Gym profile" (CoachTeamProfileScreen).
