## Design decision (deviation from the Opus fix rule wording)
- Opus fix rule step 2 says DELETE each draft (deleted:true). Stripe's API forbids it for subscription invoices: "once an invoice has
  been finalized or if an invoice is for a subscription, it must be voided" (https://docs.stripe.com/api/invoices/delete). A DELETE
  of a subscription draft always fails, so that rule would retry forever. The fence is therefore: finalize with auto_advance=false
  (confirmed same id, status open; no payment attempt) and void (confirmed void), each on a CAS-renewed lease. A failed finalize or
  void = retry, no DELETE (same property as the failed delete in the rule). Drafts count toward TRIAL_CONFLICT_MAX_VOIDS.
