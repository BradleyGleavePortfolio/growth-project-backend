are shown with a middle-dot (`·`) standing in for the space so this
inventory can itself never trip the very scanner that reads `src/`.

| Token | Default severity | Intent |
|---|---|---|
| `STUB` | BLOCK_SHIP | Marks an unwired implementation |
| `MOCK` | WARN | May be a mock that leaked out of tests |
| `FAKE` | WARN | Placeholder value |
| `PLACEHOLDER` | BLOCK_SHIP | Documented placeholder |
| `TODO_BEFORE_SHIP` | BLOCK_SHIP | Explicit pre-ship blocker |
| `XXX_NEEDS_OPERATOR` | BLOCK_SHIP | Operator action required |
| `Coming·soon` | BLOCK_SHIP | User-facing placeholder string |
| `lorem·ipsum` | BLOCK_SHIP | Placeholder copy |
